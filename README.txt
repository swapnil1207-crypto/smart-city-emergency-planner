SMART CITY EMERGENCY PLANNER WEBSITE

Files:
- index.html: complete website (HTML, CSS and JavaScript in one file)

How to run:
1. Extract the ZIP file.
2. Open the smart-city-emergency-planner folder.
3. Double-click index.html, or right-click it and open with Chrome/Edge.
4. No installation or internet connection is required.

Features:
- Interactive city road network based on the provided C program
- Dijkstra shortest-path route calculation
- Block and reopen connected roads
- Find nearest reachable hospital, fire station, or emergency shelter
- Reset road status
- Responsive layout for desktop and mobile

Important:
This website recreates the logic in a browser. It uses the sample road distances from the C code and does not provide live traffic, GPS, or actual emergency dispatch.
